# Better Whips

A Minecraft mod that brings whips to life with procedural physics.

Built for **Minecraft 1.21.1** and **NeoForge**.

## Features

- Physics-driven whip movement that responds to the player's swings.
- Hit detection along the whip's length.
- A range of whips with distinct combat effects, including lightning, crystal, slime, and water abilities.
- Custom rendering and shader effects.

## Source

This repository contains the mod's Java code, shaders, translations, and gameplay configuration. Build scripts and game assets are maintained separately.
